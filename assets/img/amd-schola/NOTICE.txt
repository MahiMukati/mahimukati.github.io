AMD Schola for Unity — media attribution

Return to Base screenshots, editor workflow mockups, and the early architecture
diagram are project artifacts created by Mohammad Mahi Ali Mukati for the
AMD–University of Toronto experiential industry project. The demo uses the
team's Unity runtime components. AMD Schola is an AMD project; this portfolio
case study describes the student team's Unity extension.
